# Файловый менеджер
Реализация файлового менеджера без дополнительных фреймворков.

Стек: 
* Java 21
* Maven
* Паттерн MVC

Во время выполнения проекта соблюдал Java code conversions, 
придерживался структуре MVC, использовал Javadoc максимально оптимально.

Поставил для себя задачу выдавать максимальную информацию
об объектах файловой системы, поэтому решил использовать многопоточность
и рекурсию для прохода по файловому дереву. Благодаря этому получилось
выдавать следующую информацию об объектах:
* Объект является директорией или файлом 
(если файл, то дополнительно указывается его тип)
* Размер объекта (для директории 0)
* Права доступа
* Количество содержимых объектов (для файла 0)
* Размер содержимого объекта (для файла 0)

Возможности файлового менеджера:
* Создание нового пустого файла
* Создание новой пустой директории
* Удаление файла или директории
* Переход в директорию или выше по файловому дереву
* Обновление списка объектов
